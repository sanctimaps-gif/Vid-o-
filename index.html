Vid-O

L'adresse de votre site, une consigne, et vous repartez avec des Shorts verticaux prêts à publier — titre et description compris.

Gratuit · sans compte · tout se passe sur votre appareil

Le nombre de vidéos est déduit de votre phrase.

Un fichier de votre appareil, dont vous détenez les droits.

Vid-O illustre d'abord avec les images trouvées sur votre site. Celles que vous ajoutez ici viennent compléter, et servent de secours quand votre hébergeur empêche un navigateur de lire vos visuels.

Sans clé, les scripts sont assemblés à partir de tournures préécrites : le sujet et le nombre de vidéos suivent votre consigne, mais pas une demande détaillée. Avec une clé d'un palier gratuit — Groq ou Google AI Studio, sans carte bancaire — c'est un vrai modèle qui écrit et votre consigne est suivie à la lettre. La clé reste dans ce navigateur.

Comment ça marche

        
    
          
  1. 
            Lecture du site. Vid-O ouvre votre page et repère les fiches :
            catalogue Shopify, données structurées, liens de boutique — mais aussi, sur un site de
            contenu, les pages d'un même dossier qui ne diffèrent que par leur nom. C'est ainsi
            qu'il trouve vos saints, vos lieux ou vos monuments sans qu'on ait à lui apprendre
            votre vocabulaire. Il en tire les noms, les descriptions, les prix s'il y en a, et les
            photos — cherchées partout : balises images, srcset, fonds déclarés en
            style, et sur vos autres pages quand la première en donne peu.
          
    2. 
          
  2. 
            Une vidéo par sujet. Une fiche sans prix n'est pas un article en
            vente : Vid-O la présente au lieu de la vendre. Chaque vidéo ouvre sur la page de son
            sujet, son adresse affichée à l'écran, et y reste du début à la fin — une vidéo sur un
            saint ne bascule pas sur la page d'un autre au milieu. Votre consigne décide de qui
            passe en premier : nommez-le, et c'est lui qui est présenté.
          
    3. 
          
  3. 
            Visite du site. Vid-O ne se contente pas de la page d'accueil : il en
            photographie aussi deux autres, celles qui montrent quelque chose, et la vidéo suit ce
            parcours — l'adresse affichée change avec la page. Surtout, il attend. Si votre site
            se construit tout seul après l'affichage — une carte interactive, une
            application — Vid-O le reconnaît et laisse la page finir : il vérifie sur l'image
            elle-même que la carte est bien dessinée, et redemande une capture plus tardive tant
            que ce n'est pas le cas. C'est ce qui évite de filmer un cadre vide à la place de
            votre carte. Comptez quelques dizaines de secondes de plus sur ces sites-là : c'est le
            prix d'une carte visible.
          
    4. 
          
  4. 
            Quand votre site n'a pas de photos. Une carte, une application : la
            page ne contient aucune image à récupérer, il n'y a rien à reprocher au site. Les vues
            prises pendant la visite deviennent alors les visuels des vidéos — chaque plan parcourt
            une portion différente d'une page réelle, chargée pour de bon. Vos propres images, si
            vous en ajoutez, passent devant.
          
    5. 
          
  5. 
            Écriture. Votre consigne décide du sujet : les mots qu'elle contient
            servent à choisir les produits ou les sections mises en avant. Les scripts sont ensuite
            composés à partir des seules données du site — aucun prix ni aucune caractéristique
            n'est inventé. Seul le texte destiné à être lu est retenu : ni le code de la page, ni
            les menus, ni les pieds de page ne passent dans la voix off. Avec une clé de modèle gratuite, c'est un vrai modèle qui écrit et la
            consigne est suivie dans le détail.
          
    6. 
          
  6. 
            Montage. La vidéo s'ouvre sur votre page réelle, plein écran, qui
            défile comme si on la parcourait, avec l'adresse exacte de la page affichée dessus ;
            puis elle enchaîne vos visuels plein cadre et se referme sur une autre page du site. Voix off, musique,
            sous-titres et votre couleur de marque — tirée de vos propres images — sont assemblés
            et enregistrés par votre navigateur. La voix off lit les sous-titres mot pour mot.
            Aucune musique n'est ajoutée sans que vous l'ayez demandée. Le montage continue en
            arrière-plan : l'écran reste allumé tout seul, et changer d'onglet ne l'interrompt pas.
          
    7. 
        

        

          Votre navigateur n'a pas le droit de lire une page d'un autre domaine. Vid-O essaie donc
          plusieurs chemins de front — accès direct et plusieurs relais publics — et garde le
          premier qui répond ; si la page est construite en JavaScript, un lecteur l'exécute avant
          de la renvoyer. L'adresse que vous saisissez transite alors par l'un de ces services.
          Sur un site privé ou protégé par mot de passe, préférez la version ordinateur ci-dessous,
          qui lit les sites directement.
        

      


      

        
Filmer votre site en fonctionnement

        

          Cette page compose des vidéos : elle lit votre site, en tire textes et
          images, et monte des plans. Pour montrer une interface qui bouge — une
          carte qu'on déplace, un repère qu'on ouvre, une recherche qu'on saisit — il faut
          filmer le site pendant qu'on s'en sert. Vid-O sait le faire, mais pas
          depuis cette page : le JavaScript d'un site n'a pas le droit de lire les pixels d'un
          autre site, ni par iframe ni autrement. Il faut un navigateur qu'on pilote.
        

        

          Depuis un téléphone : ouvrez l'onglet
          Actions du dépôt, lancez
          « Visite filmée », saisissez l'adresse de votre site. GitHub ouvre le navigateur à votre
          place et vous rend le MP4 dans les fichiers joints à l'exécution.
        

        
npm install playwright && npx playwright install chromium
npm run tour -- "https://ma-carte.fr" --seconds 20 --music ./musique.mp3

        

          Vid-O attend que votre carte ait fini de se dessiner, puis se sert du
          site : il la déplace, zoome, ouvre un repère, va chercher la recherche — même
          rangée dans un menu —, tape la requête lettre par lettre, laisse la liste se remplir et
          ouvre un résultat. C'est une démonstration de ce que votre site sait faire. Le mot
          recherché est déduit de vos propres intitulés, pour qu'il ramène vraiment quelque chose.
          La vidéo se termine sur une carte de fin reprenant le nom et la description de votre
          site, avec votre musique.
        

      


      

        
La version ordinateur

        

          Cette page monte des vidéos complètes, voix off et musique comprises. La version
          ordinateur va plus loin : export MP4 H.264 garanti, exploration de bien plus de pages,
          voix neuronales de meilleure qualité, et choix du rédacteur des scripts — dont un modèle
          qui tourne chez vous, via Ollama.
        

        
git clone https://github.com/sanctimaps-gif/Vid-o-.git
cd Vid-o-
npm install
npm run dev -- "https://ma-boutique.fr" "fais 5 vidéos sur les 5 meilleures tenues"
