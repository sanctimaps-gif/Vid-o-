Comment ça marche

  1. Lecture du site. Vid-O ouvre votre page, repère les fiches produit — catalogue Shopify, données structurées, liens de boutique — et en tire les noms, les prix, les descriptions et les photos.
  2. Écriture. Les scripts sont composés à partir de ces seules données : accroche, scènes, textes incrustés, titre et description YouTube. Aucun prix ni aucune caractéristique n'est inventé.
  3. Montage. Chaque scène est dessinée en 9:16 : la photo posée sur son propre flou plein cadre, un léger zoom, les sous-titres, votre couleur de marque tirée de vos visuels, une barre de progression. La vidéo est enregistrée par votre navigateur.

Votre navigateur n'a pas le droit de lire une page d'un autre domaine. Quand l'accès direct échoue, Vid-O passe par un relais public (allorigins, corsproxy, codetabs) : l'adresse que vous saisissez transite alors par ce service. Sur un site privé ou protégé, préférez la version ordinateur ci-dessous, qui lit les sites directement.

La version ordinateur

Cette page fait le montage complet, mais votre navigateur ne peut pas enregistrer une voix de synthèse dans un fichier vidéo. La version ordinateur ajoute la voix off automatique, l'export MP4 H.264, l'exploration de plus de pages et le choix du rédacteur (dont un modèle local via Ollama). 

git clone https://github.com/sanctimaps-gif/Vid-o-.git
cd Vid-o-
npm install
npm run dev -- "https://ma-boutique.fr" "fais 5 vidéos sur les 5 meilleures tenues"
