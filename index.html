Vid-O

L'adresse de votre site, une consigne, et vous repartez avec des Shorts verticaux prêts à publier — titre et description compris.

Gratuit · sans compte · tout se passe sur votre appareil

Le nombre de vidéos est déduit de votre phrase.

Un fichier de votre appareil, dont vous détenez les droits.

Sans clé, les scripts sont assemblés à partir de tournures préécrites : le sujet et le nombre de vidéos suivent votre consigne, mais pas une demande détaillée. Avec une clé d'un palier gratuit — Groq ou Google AI Studio, sans carte bancaire — c'est un vrai modèle qui écrit et votre consigne est suivie à la lettre. La clé reste dans ce navigateur.

Comment ça marche

        
    
          
  1. 
            Lecture du site. Vid-O ouvre votre page, repère les fiches produit —
            catalogue Shopify, données structurées, liens de boutique — et en tire les noms, les
            prix, les descriptions et les photos.
          
    2. 
          
  2. 
            Écriture. Votre consigne décide du sujet : les mots qu'elle contient
            servent à choisir les produits ou les sections mises en avant. Les scripts sont ensuite
            composés à partir des seules données du site — aucun prix ni aucune caractéristique
            n'est inventé. Avec une clé de modèle gratuite, c'est un vrai modèle qui écrit et la
            consigne est suivie dans le détail.
          
    3. 
          
  3. 
            Montage. La vidéo s'ouvre sur votre page réelle, plein écran, qui
            défile comme si on la parcourait, avec votre adresse affichée dessus ; puis elle
            enchaîne vos visuels plein cadre et se referme sur la page. Voix off, musique,
            sous-titres et votre couleur de marque — tirée de vos propres images — sont assemblés
            et enregistrés par votre navigateur. La voix off lit les sous-titres mot pour mot.
            Aucune musique n'est ajoutée sans que vous l'ayez demandée. Le montage continue en
            arrière-plan : l'écran reste allumé tout seul, et changer d'onglet ne l'interrompt pas.
          
    4. 
        

        

          Votre navigateur n'a pas le droit de lire une page d'un autre domaine. Vid-O essaie donc
          plusieurs chemins de front — accès direct et plusieurs relais publics — et garde le
          premier qui répond ; si la page est construite en JavaScript, un lecteur l'exécute avant
          de la renvoyer. L'adresse que vous saisissez transite alors par l'un de ces services.
          Sur un site privé ou protégé par mot de passe, préférez la version ordinateur ci-dessous,
          qui lit les sites directement.
        

      


      

        
La version ordinateur

        

          Cette page monte des vidéos complètes, voix off et musique comprises. La version
          ordinateur va plus loin : export MP4 H.264 garanti, exploration de bien plus de pages,
          voix neuronales de meilleure qualité, et choix du rédacteur des scripts — dont un modèle
          qui tourne chez vous, via Ollama.
        

        
git clone https://github.com/sanctimaps-gif/Vid-o-.git
cd Vid-o-
npm install
npm run dev -- "https://ma-boutique.fr" "fais 5 vidéos sur les 5 meilleures tenues"
